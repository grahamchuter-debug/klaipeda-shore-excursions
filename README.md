# Klaipėda Shore Excursions

Independent Klaipėda cruise planning site for Baltic passengers — Old Town, Curonian Spit and editorial shore excursion guidance.

**Domain:** https://klaipedashoreexcursions.com

## Development

```bash
npm install
npm run download-images
npm run dev
```

## QA

```bash
npm run build
npm run check-links
npm run seo-qa
```

## Deploy

```bash
npm run pages:deploy
```
